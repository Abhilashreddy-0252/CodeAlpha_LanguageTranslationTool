System Architecture & Technical Design

AI Language Translation Tool Technical Overview

Dual Presentation Layer (Desktop GUI & Web API)

Designed with a modular architecture decoupling backend translation services from UI components. Operates both as a native Python Tkinter desktop GUI application and as a Flask REST server serving an interactive web interface.

API Resilience & Circuit-Breaker Fallback

Integrates Google Cloud Translation API v2 with automatic fallback translation engine handling. In case of API quota limits or unconfigured keys, the app seamlessly handles requests without crashing.

Asynchronous Speech Streaming

Uses gTTS (Google Text-to-Speech) for text-to-speech audio synthesis across 21 global and regional Indian languages, streamed asynchronously in background threads to avoid main looper blocking.

Project File Structure

main.py (Tkinter GUI) | app_web.py (Flask Web API) | translator.py (API Engine)
speech.py (gTTS Audio) | languages.py (ISO Mappings) | config.py (Environment)
